# 🐾 PETLY

PETLY is a modern pet adoption and pet care platform that brings together pet owners, adopters, shelters, and veterinary services in one place. Built using React and Vite, the application focuses on delivering a clean, responsive, and intuitive user experience.

## Features

- Pet adoption listings
- Detailed pet profiles
- Pet health and care resources
- AI Pet Assistant interface
- Community section
- Pet products and services
- Responsive design
- Modern UI/UX

## Tech Stack

- React
- Vite
- JavaScript
- HTML
- CSS

## Future Improvements

- Backend integration
- User authentication
- Real-time messaging
- Online appointment booking
- AI-powered recommendations

## Installation

```bash
git clone https://github.com/Swathi96-debug/PETLY-Website.git
cd PETLY-Website
npm install
npm run dev
```
